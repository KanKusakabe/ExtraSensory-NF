ExtraSensory-NF

実生活のスマホ/時計センサ（60人・毎分の行動＋文脈）を条件付き Normalizing Flow で学習。『いまの行動の意外さ』と『生活型の個人差』を確率で扱う。

条件付き Normalizing Flow で「その人の"いつも"の密度」を学習し、 SURPRISE = -log p や生成・潜在で使う。各カードが1つのモデル（バリエーション）。 ページを開くと データ / 学習方法 / 結果 / 図の見方 / 解釈と使い道 が分かる。

元データの中身（何が入っているか）

生データ＝ExtraSensory の per-user CSV（<uuid>.features_labels.csv.gz）。1行＝1分の記録で、278列＝timestamp ＋ 加速度/ジャイロ/音/位置などの約225センサ特徴 ＋ label:*（自己申告の文脈：SITTING / WALKING / SLEEPING / IN_A_MEETING / LOC_home …）。
使ったのは、頑健な加速度magnitudeの6統計量（mean/std/25/50/75%/エントロピー）を1分ごとの行動ベクトルに、文脈ラベルは評価に使用。60人・約377,000分行。
1レコードの実例：ある1分で 加速度mean=1.01・std=0.03…、その時の自己申告ラベル SITTING=1, LOC_home=1。
